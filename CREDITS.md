# Sources

- CowboyBingus: Bingus Shared Loader v18 / API1, supplied locally by the user.
- User-supplied R-36 Eruptor Forward Fragments v2.3: reference for record layout and ModOptionsMenu interfaces; inspected read-only.
- [xypwn/filediver](https://github.com/xypwn/filediver): extracted current data, schema reference and archive format research.
- [shalzuth/HelldiversData](https://github.com/shalzuth/HelldiversData): April16,2024 original projectile, explosion and damage records.
- [The Helldivers Wiki](https://helldivers.wiki.gg/wiki/R-36_Eruptor): change history and current weapon statistics.

Runtime Lua and build/test tools written for this request. Game assets, shared loader and third-party addon binaries are not bundled.
